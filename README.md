# Tamil Nadu Election 2026 Analysis

This project analyzes Tamil Nadu Election 2026 data using Python and Google Colab.

## Research Questions

* Seat Flip Analysis
* Vote Share Analysis
* Margin Analysis

## Tools Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Key Insights

* Large number of seat flips observed
* Multiple close electoral contests
* Vote share significantly influenced seat outcomes
